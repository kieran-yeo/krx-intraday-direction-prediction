# 장 초반 2시간 데이터로 종목별 당일 주가 방향 예측

**제1회 KRX 금융 빅데이터 활용 아이디어 경진대회 (한국거래소, 2022) 최종 2위 (우수상) · 팀 Micro-A.N.T** · [English](README.md)

[최종 순위 (DACON)](https://dacon.io/competitions/official/235914/leaderboard) · 관련 기사: [이투데이](https://www.etoday.co.kr/news/view/2173163), [매일경제](https://www.mk.co.kr/news/stock/10457335)

09:00~11:00의 1분 단위 한국거래소(KRX) 데이터로 KOSPI 종목의 **당일 종가가 시가보다 높게 끝날지**를 예측했습니다. 외국인 수급, 호가·주문 기반 미시구조 지표(스프레드, 호가 깊이, 주문 불균형, 취소율), 장중 추세 지표로 피처를 만들고, 로지스틱 회귀부터 CatBoost, 신경망까지 6개 모델을 비교했습니다.

대회 이후 결과를 다시 검증했습니다. 이후 기간에서도 성능은 유지됐지만, **단순 규칙보다 높았던 성능은 미래 정보 누수에서 나온 것이었습니다.** 이 저장소에는 대회 제출본과 재검증이 함께 들어 있습니다.

## 핵심 결과

| | 정확도 |
|---|---|
| 대회 결과 (CatBoost, 무작위 7:3 분할) | 0.830 |
| 기준선 규칙: "11시 가격이 시가보다 높으면 상승" (2022년) | 0.800 |
| CatBoost, 11시에 알 수 있는 피처, 2019~21 학습 → 2022 평가 | 0.801 |
| 위 모델 + 대회 때의 거래대금/시가총액 피처 | 0.842 |
| 위 모델 + 같은 피처를 전일 종가로 계산 | 0.801 |

1. **기간 기준 검증은 통과했습니다.** 2019~2021년으로 학습하고 2022년으로 평가해도 모든 모델의 정확도 변화가 약 0.1%p 이내였습니다.
2. **어떤 모델도 한 줄짜리 규칙을 넘지 못했습니다.** 장 초반 2시간 동안 오른 종목은 대체로 시가보다 높게 끝나서, 규칙만으로 80%를 맞힙니다. CatBoost가 이 규칙과 다르게 예측한 경우는 2.4%였고, 그중 맞힌 비율은 절반 정도였습니다.
3. **대회 점수에는 누수가 있었습니다.** 한 피처가 오전 거래대금을 일별 `시가총액`으로 나눴는데, 이 시가총액이 모든 행에서 **당일 종가 × 상장주식수**였습니다. 종가는 15시 30분에 정해지므로 11시 예측에는 쓸 수 없습니다. 이 피처를 넣으면 2022년 정확도가 약 4%p 오르고, 전일 종가로 다시 계산하면 그 효과가 사라집니다.

전체 분석: [`notebooks/01_validation_and_leakage.ipynb`](notebooks/01_validation_and_leakage.ipynb) (영문)

## 배운 점

- 단순 기준선과 먼저 비교합니다. 기준선 대비 3%p 향상이었다면 의심스러워 보였겠지만, 막연히 50%와 비교한 0.83은 인상적으로 보였습니다.
- 섞은 데이터뿐 아니라 이후 기간으로도 검증합니다.
- 모든 입력값이 예측 시점에 실제로 알 수 있는 값인지 확인합니다. 장 마감 후 파일에서 가져온 값은 특히 주의합니다.

## 분석 흐름 (대회)

```
일별, 일중(1분·10분), 투자자별 데이터 로드
 → 09:00~11:00 구간 추출, 외국인 거래 분리
 → 피처 24개 생성 (수급, 정보비대칭, 추세)
 → 우선주·SPAC, 결측·무한값 제거
 → EDA: 분포, 윈저화(양쪽 0.5%), Q-Q plot, Anderson-Darling 검정
 → 단계적 변수 선택 (AIC, p < 0.05) → 22개, 상관계수·VIF 확인
 → 모델: 로지스틱 회귀, 의사결정나무, 랜덤포레스트, XGBoost, CatBoost, 신경망
 → 다른 분할로 강건성 확인
```

| 그룹 | 피처 |
|---|---|
| 수급 | 외국인 순매수(금액, 거래량), 외국인 체결강도, 수정거래회전율, 거래대금/시가총액 |
| 정보비대칭 | 호가·비율 스프레드, HS 역선택비용, 호가 깊이, 주문 취소율, 거래·주문 불균형, 전량가중평균지정가/종가 |
| 추세 | 일중강도, DVI, TRIN, PPP(피봇 포인트 위치), MFI, 1분·10분 변동률 |
